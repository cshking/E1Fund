# E1栋电梯公共资金收支管理系统（GitHub Pages 静态版）

纯前端单页应用，**无需服务器、无需令牌**，可直接托管到 GitHub Pages。
功能与后端版一致：管理员登录（多管理员、分级权限）、录入/修改/删除收支记录（佐证附件必填 ≤5MB）、
游客免登录按时间段浏览与导出电子表格、操作日志审计。

## 重要说明（与后端版的区别）
- **数据保存在访问者自己的浏览器（IndexedDB）**，不依赖服务器。好处：完全静态、可跑在 GitHub Pages、零成本。
- 代价：**同一浏览器/设备的数据互通，跨设备/跨人默认不共享**。本快照已内置 8 户集资款初始数据（合计 273,220 元）。
- 若需要"多人实时共享账本"，请改用带后端的版本（见仓库其他分支或联系维护者）。

## 功能
- 管理员：账号密码登录（密码 SHA-256 哈希，不存明文）；录入收入/支出（日期、类型、金额、事项说明、经办人、佐证附件必填≤5MB）；
  修改/删除自己录入的记录；查看全部流水与汇总；修改密码；**超管(admin)可新增/删除/重置其他管理员密码**；操作日志自动留痕。
- 游客：浏览明细与佐证附件；按时间段（起止日期）筛选；导出 Excel 电子表格（.xlsx）。
- 安全：管理接口仅在登录后可见/可操作；非超管无法访问账号管理。

## 本地预览
直接用浏览器打开 `index.html` 即可（建议用本地静态服务器以避免个别浏览器对 file:// 的限制）：
```
cd 1014V2
python -m http.server 8080
# 浏览器访问 http://localhost:8080/
```

## 发布到 GitHub Pages
1. 把本目录全部文件（`index.html`、`admin.html`、`assets/`、`README.md`）上传到您的 GitHub 仓库（如 `E1Fund`）。
2. 仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 **main**（或您用的默认分支）、目录选 **/ (root)** → 保存。
3. 稍等约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/` 即可。
   - 公开浏览：`https://<用户名>.github.io/<仓库名>/`
   - 管理登录：`https://<用户名>.github.io/<仓库名>/admin.html`

## 默认管理员
- 账号 `admin` / 密码 `admin123`，请登录后到"修改密码"立即修改。
- 新增其他管理员：用 admin 登录 → 顶部"管理员管理" → 填写账号/密码/显示名 → 创建（普通管理员不可管理其他账号）。
