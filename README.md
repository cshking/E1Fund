# E1栋电梯公共资金收支管理系统

金牛生态小区E1栋一单元加装电梯 **公共资金收支** 透明管理系统。管理员登录后录入收支（佐证附件必填），
业主（游客）免登录即可按时间段浏览全部明细、查看佐证附件、导出 Excel 电子表格，实现资金公开可监督。

## 技术栈
- 后端：Python + Flask
- 数据库：SQLite（单文件 `fund.db`，无需安装数据库服务）
- 附件：存于 `uploads/` 目录，数据库仅存文件路径
- 导出：openpyxl 生成 Excel（.xlsx）
- 前端：原生 HTML/CSS，响应式（电脑 / 手机均可正常浏览使用）

## 功能
- **管理员（支持多管理员，分级权限）**：账号密码登录（session/cookie）。
  - **超级管理员（固定为 `admin`）**：拥有全部权限，包括"管理员管理"
    （新增账号 / 重置密码 / 删除账号，不能删除自己，至少保留 1 个账号）。
  - **普通管理员（由 admin 创建）**：可录入收入/支出（日期、类型、金额、事项说明、经办人、佐证附件必填≤5MB）；
    查看/修改/删除**自己**录入的记录；查看全部流水与汇总（总收入/总支出/余额）；修改自己的密码；
    查看"操作日志"。**但不可进行账号管理（新增/删除/重置其他管理员密码）**，相关入口仅 admin 可见，
    直接访问亦会被拦截并提示"仅超级管理员(admin)可进行账号管理操作"。
- **游客（免登录）**：浏览公开明细与每条记录的佐证附件；**按时间段（起始/截止日期）筛选**收支；
  **导出 Excel 电子表格（.xlsx）** 供存档或核对。
- **操作日志（审计留痕）**：所有管理员的关键操作（登录/退出/新增/修改/删除记录/改密码/账号管理/导出）
  均自动记录操作人、时间、IP、详情，管理员可在"操作日志"页追溯，便于监督。
- **安全底线**：密码 werkzeug 哈希存储（绝不明文）；管理接口均 `@login_required`，游客无法绕过登录进入管理页；
  附件上传限 5MB 并校验类型。

## 运行方式（Windows）
1. 安装依赖（用本机 Python 或自带的虚拟环境）：
   ```
   pip install -r requirements.txt
   ```
   或直接使用已配置的运行环境（见下方"一键启动"）。
2. 启动：
   ```
   python app.py
   ```
   首次启动会自动建库（`fund.db`，含 logs 表）并导入初始数据。

## 一键启动（本机已配置的运行环境）
```
c:\Users\Administrator\.workbuddy\binaries\python\envs\e1fund\Scripts\python.exe "D:\Users\User\Desktop\电梯\E1电梯公共资金收支管理系统\app.py"
```

## 访问方式
服务默认监听 `0.0.0.0:5000`：
- 本机（管理员/业主）：浏览器打开 http://localhost:5000
- 同局域网其他业主（手机/电脑）：浏览器打开 http://<本机局域网IP>:5000
  （查看本机 IP：Windows 命令行 `ipconfig`，取"IPv4 地址"，如 192.168.x.x）
- 公开浏览首页（游客，免登录）：http://localhost:5000/
- 游客导出电子表格：首页"查询与导出"区 → 选时间段 → 点"导出电子表格"
- 管理员登录：http://localhost:5000/login
- 管理员管理：登录后顶部导航"管理员管理"
- 操作日志：登录后顶部导航"操作日志"
- 佐证附件：每条明细的"查看佐证"链接，游客也可打开监督

> 若 5000 端口被占用，修改 `app.py` 末尾 `app.run(port=5000)` 为其他端口（如 8080）。

## 部署到公网（让其他管理员可登录管理）

> ⚠️ **GitHub Pages 只能托管纯静态网页，无法运行本系統的 Python 后端**，因此 github.io 无法直接提供"管理员登录/录入"功能。
> 正确做法：以 **GitHub 仓库作为代码源**，连接一个支持 Python 的免费托管（如 Render），由它从仓库拉取代码自动部署成一个公网 Web 服务。代码始终在您的 GitHub 仓库里，管理员用生成的公网地址登录即可管理。

### 方式 A：Render（推荐，免费，连 GitHub 仓库一键部署）
1. 打开 https://render.com 注册并登录（可用 GitHub 账号授权）。
2. 点 **New → Web Service** → 选择 **Connect a repository** → 授权并选择本仓库 `cshking/E1Fund`。
3. 配置（仓库已自带 `render.yaml`，多数自动填好）：
   - Runtime：**Python 3**
   - Build Command：`pip install -r requirements.txt`
   - Start Command：`gunicorn -w 1 -b 0.0.0.0:$PORT app:app`
   - Plan：**Free**
4. 点 **Create Web Service**，等待构建完成，Render 会给出一个形如 `https://e1fund-xxxx.onrender.com` 的公网地址。
5. 部署后务必：到 Render 的 **Environment** 中把 `E1FUND_SECRET` 设为您自定义的随机串；并登录系统修改默认管理员 `admin/admin123`。

### 方式 B：WorkBuddy 一键发布（已内置，最快）
本系统已通过"发布为应用"发布，分享链接：https://e1fund.app.workbuddy.host/ （管理员登录 `/login`，默认 admin/admin123）。

### 数据持久化说明
- 部署实例使用内置 SQLite（`fund.db`），数据保存在托管实例磁盘上；**重新部署/改代码会重置为初始示例数据**（已内置 8 户集资款 273,220 元）。
- 若需线上长期累积真实记录，建议将数据库改为云数据库（如 Supabase），或直接在本机局域网运行并定期备份 `fund.db` 与 `uploads/`。
